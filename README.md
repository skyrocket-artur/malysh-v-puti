# Малыш в пути

Развивающая игра для детей 3 лет, чтобы занять ребёнка в самолёте или машине. Около часа игры: три острова по 10 уровней. Работает на телефоне без интернета (PWA).

## Острова и уровни

| Остров | Герои | Уровни |
|---|---|---|
| Путешествие | котята Бублик, Ириска, Пончик | чемодан, раскраска-самолёт, найди чемодан, пристегнись, взлёт и «зевни», счёт облачков, протри окошко, пазл, дорожка к бабушке, носочки парами |
| Музыка | лягушонок Квак | цветные барабаны, кто так говорит, повтори мелодию, танцуй — замри, громко — тихо, раскраска-бабочка, пузыри-нотки, оркестр теней, поющая пирамидка, колыбельная |
| Добрые дела | мишка Топа, зайка Пуша | помой лапки, почисти зубки, убери игрушки, фигурки-домики, как помочь другу, раскраска-домик, матрёшки, пазл, угости друзей, дышим как ёжик |

Каждый уровень заканчивается так: наклейка → вывод (правило поведения) → задание «по-настоящему» (найти, нарисовать, собрать без телефона). Выводы, задания и совет для каждого уровня есть в разделе «Для родителей»: удерживайте ⚙️ на главном экране.

## Запуск

```bash
python3 -m http.server 8777
```

Затем откройте http://localhost:8777. Для телефона и офлайна игру нужно выложить на HTTPS-хостинг (например, GitHub Pages), открыть один раз с интернетом и добавить на экран «Домой».

## Озвучка

Сейчас все 295 реплик озвучивает синтезатор речи телефона. Чтобы заменить их своим голосом:

1. Откройте `script.html` (или `VOICE_SCRIPT.md`): там все фразы с ID.
2. Запишите либо каждую фразу отдельным файлом с именем ID (`a01_i.m4a`), либо весь уровень одним файлом с паузами 2–3 секунды.
3. Подключите записи:
   ```bash
   node tools/import-voice.js ~/Downloads/записи
   ```
   или, для одного длинного файла на уровень:
   ```bash
   node tools/import-voice.js --split ~/Downloads/a01.m4a --level a01
   ```

Скрипт обрежет тишину, выровняет громкость, положит файлы в `audio/voice/` и обновит список. Реплики, которые ещё не записаны, так и будут звучать синтезатором.

После изменения текстов в `js/levels.js` обновите сценарий: `node tools/make-script.js`.

## Устройство

- `js/levels.js` — всё содержание: реплики, уровни, выводы, задания, советы.
- `js/engines.js`, `js/engines2.js` — 14 игровых механик.
- `js/art.js` — персонажи и предметы в SVG, раскраски.
- `js/audio.js` — звуки и музыка (синтезируются, файлов нет) и озвучка.
- `js/app.js` — экраны и сценарий уровня.
- `sw.js` — офлайн-кэш. После изменений поменяйте `VERSION` (это делает `tools/scan-voice.js`).
- `print.html` — раскраски для печати.

Персонажи нарисованы свои, «в духе» популярных мультиков. Чужих героев («Три кота», «Фиксики», Crazy Frog) в игре нет: их нельзя публиковать без лицензии.
